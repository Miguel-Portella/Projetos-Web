## Overview
This project is the final project of my backend development course, fully designed and implemented independently. The main objective was to build a functional backend system with structured logic, data persistence, and clear control flow using PHP and MySQL.

Rather than focusing on visual design or frameworks, the project emphasizes backend reasoning, data handling, and system reliability.

## System Architecture
- Backend Language: PHP
- Database: MySQL
- Data Flow: Server-side processing with form handling
- Architecture Focus: Clear separation of logic and maintainable structure

## Key Features
- Input validation and sanitization
- Server-side data processing
- Database integration using MySQL
- Structured control flow for backend operations
- Basic error handling to ensure system stability

## Engineering Decisions
- Prioritized clarity and reliability over unnecessary complexity
- Organized backend logic to simplify debugging and maintenance
- Chose a straightforward architecture to better understand system behavior
- Focused on correctness and predictability in data processing

## Challenges & Problem Solving
- Designing consistent data flow between user input and database storage
- Debugging logical errors in backend processing
- Ensuring proper validation to avoid inconsistent or invalid data
- Managing database interactions reliably

## Skills Demonstrated
- Backend system reasoning
- Data flow control and persistence
- Problem-solving and debugging
- Independent project development
- Practical use of PHP and MySQL

## Academic Context
This project represents applied learning in backend development and reflects my interest in system-oriented programming and applied artificial intelligence, where backend reliability and data integrity are fundamental.
